# Document OS 1.0

**A lightweight, persistent, terminal-based operating system** designed for business productivity and personal use.

---

## About

Document OS is a custom operating system simulator built as the official system for **Document** company. It runs entirely in the terminal and gives you a real mini OS experience.

## Features

- Persistent Filesystem – Everything you create is automatically saved
- Secure User Accounts with login system
- Simple and easy-to-use commands
- Built-in Business Tools
- Full file management (create, read, write, delete, copy, rename, etc.)

## Business Tools Included

- Task Manager (`todo`)
- Quick Notes (`note`)
- Contact Manager (`contacts`)
- Calculator (`calc`)
- Simple Text Editor (`edit`)

2. Open **PowerShell** as normal user.
